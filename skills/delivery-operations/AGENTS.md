# Delivery operations skills

This category owns the optional release-train coordination and Markdown wiki playbooks. Each package is independently usable and ships in the dedicated `delivery-operations` marketplace bundle.

- `release-train-supervisor` owns verified Driver dispatch, one-shot monitoring and exact handoff. Herdr is one terminal adapter. The adopting repository owns phase admission, grants and task state.
- `wiki-delivery-sync` owns portable vault navigation, reciprocal private pointers, stable Change Briefs and evidence-bound closeout. Keep templates synthetic and preserve project records. The two skills share the checkpoint format documented by their templates. One authorized writer updates the checkpoint pair.
- Keep support files package-relative and verify exact package inventories, mocked terminal and scheduler behavior, and temporary vault scenarios. Keep live vaults and installed profiles outside these tests.
